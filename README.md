# Ramen Rating Prediction 🍜
## Overview
Project uses dataset from Kaggle that includes ratings of various instant ramen flavours all over the world. Using a machine learing model, you can predict what rating should get your favourite ramen based on its flavour profile, country of origin, brand and packaging!

## Data Setup & How to Run
The dataset used is the *Ramen Ratings* from Kaggle. To keep the repository clean and respect licensing, the raw `.csv` file is not included in this repository.

To run this notebook locally:
1. Download the dataset here: [Ramen Ratings on Kaggle](https://www.kaggle.com/datasets/residentmario/ramen-ratings)
2. Extract the archive and place the `ramen-ratings.csv` file in the root directory of this project.
3. Open and run all cells in the Jupyter Notebook.
